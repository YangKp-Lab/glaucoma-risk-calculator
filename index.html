Methodological detail

Two independent LightGBM models

MLG-5 uses the same five predictors—Age, UA/eGFR, CTI, SBP, and eGDR—in two separately exported LightGBM ensembles. The retrospective model generates the MLG-5 prevalence index and prevalent glaucoma probability; the prospective model generates the MLG-5 incidence index and incident glaucoma risk. The browser traverses the original exported trees rather than a surrogate formula.

MLG-5 prevalence and incidence indices

Each displayed index translates its own model raw score so the theoretical minimum is 1:
MLG-5 prevalence index = retrospective raw score + 7.176677420327
MLG-5 incidence index = prospective raw score + 11.018220134250
The two indices come from different models and should not be compared numerically. Risk remains based on the original unshifted raw score:
Probability = 1 / [1 + exp(−raw score)]

Individual SHAP values

Tree-path-dependent SHAP values are calculated locally from the embedded exported trees. For each model:
E[f(x)] + SHAP(Age) + SHAP(UA/eGFR) + SHAP(CTI) + SHAP(SBP) + SHAP(eGDR) = f(x)
Here f(x) is the model raw score (log-odds); the displayed probability/risk is sigmoid[f(x)].

Composite-variable calculation

eGDR = 21.158 − 0.09 × WC − 3.407 × Hypertension − 0.551 × HbA1c
Hypertension is coded 1 for yes and 0 for no.
UA/eGFR = Uric acid / eGFR
eGFR uses the CKD-EPI 2021 race-free equation:
Female: 142 × min(Cr/0.7,1)^−0.241 × max(Cr/0.7,1)^−1.200 × 0.9938^Age × 1.012
Male: 142 × min(Cr/0.9,1)^−0.302 × max(Cr/0.9,1)^−1.200 × 0.9938^Age
CTI = WC(m) / [0.109 × √(Weight(kg) / Height(m))]
Raw-variable input uses waist circumference and height in cm, converts them to meters internally, and derives CTI automatically.

Batch analysis and privacy

Excel/CSV rows are parsed in the browser. Five-variable columns can be supplied directly, or raw-variable columns can be mapped and transformed before both models run. Export includes both indices, both raw scores, both risk outputs, both SHAP baselines, and all ten feature-level SHAP values. Patient rows are not sent to a prediction server.

Research use

MLG-5 is intended for research and model interpretation. It does not replace ophthalmic examination, clinical diagnosis, or independent external validation.
