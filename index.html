Research Methods

MLG-5 Index Methodology

Model Framework

The final MLG-5 model uses an Enet_a01 + NaiveBayes pipeline. Elastic net with α = 0.1 is used for feature selection, and Gaussian Naive Bayes is the final prediction algorithm. The five selected predictors are CTI, UA/eGFR, creatinine, red blood cell count, and age.

Predictor Set

CTI — Conicity Index
UA/eGFR — uric acid-to-estimated glomerular filtration rate ratio
Cr — creatinine
RBC — red blood cell count
Age — age in years

Gaussian Naive Bayes Model

For each continuous predictor, Gaussian Naive Bayes models the class-conditional distribution using a normal density. The final posterior glaucoma probability is obtained by combining the class prior with the five class-conditional densities under the Naive Bayes conditional-independence assumption.

P(Y = 1 | x) = 1 / [1 + exp(−L)] L = log(π₁/π₀) + Σⱼ { log(σ₀ⱼ/σ₁ⱼ) − (xⱼ − μ₁ⱼ)²/(2σ₁ⱼ²) + (xⱼ − μ₀ⱼ)²/(2σ₀ⱼ²) }

Expanded MLG-5 Equation

L = −12.52702605885674 − 2.452121056873750 × CTI² + 10.369294125125265 × CTI + 117.4004018796317 × (UA/eGFR)² − 12.824097899878439 × (UA/eGFR) + 3.351059812101331 × Cr² − 5.909869278500278 × Cr + 0.04158265380739734 × RBC² − 0.9274332882414846 × RBC − 0.0004537166011694817 × Age² + 0.1205213006941625 × Age Predicted probability = 1 / [1 + exp(−L)]
This expanded equation was numerically verified against the fitted Naive Bayes model to machine precision in the model-development workflow.

MLG-5 Index Transformation

The model posterior probability is linearly rescaled to a 0–10 index. This transformation preserves patient ordering and ROC discrimination because it is a strictly increasing transformation of the predicted probability.

MLG-5 Index = 10 × P(Y = 1 | x) Therefore: MLG-5 Index = 10 / [1 + exp(−L)] Index scale: 0 to 10 Higher values indicate higher model-estimated glaucoma risk.

Training Priors

The fitted Naive Bayes model used 320 glaucoma-positive and 3,827 glaucoma-negative observations in the training data. These class frequencies are incorporated into the fitted class prior.

CTI Definition

CTI represents the Conicity Index for central adiposity.

CTI = WC (m) / [0.109 × √(Weight / Height (m))]

UA/eGFR and eGFR Calculation

eGFR is calculated using the 2021 CKD-EPI creatinine equation without a race coefficient. Serum creatinine (Scr) is expressed in mg/dL, age in years, and eGFR in mL/min/1.73 m².

eGFR = 142 × min(Scr/κ, 1)^α × max(Scr/κ, 1)^−1.200 × 0.9938^Age × 1.012 [if female] κ = 0.7 for females and 0.9 for males α = −0.241 for females and −0.302 for males min(Scr/κ, 1) = the smaller of Scr/κ and 1 max(Scr/κ, 1) = the larger of Scr/κ and 1 UA/eGFR = UA / eGFR
eGFR equation: 2021 CKD-EPI creatinine equation (race-free). The UA/eGFR predictor is subsequently calculated by dividing UA by the resulting eGFR value.

Web Calculation Logic

The browser evaluates the expanded Gaussian Naive Bayes log-posterior odds equation using the five entered predictors, converts L to the posterior glaucoma probability, and then multiplies that probability by 10 to obtain the MLG-5 Index. Calculation occurs locally in the browser.

const L = -12.52702605885674 - 2.452121056873750 * CTI ** 2 + 10.369294125125265 * CTI + 117.4004018796317 * UA_eGFR ** 2 - 12.824097899878439 * UA_eGFR + 3.351059812101331 * Cr ** 2 - 5.909869278500278 * Cr + 0.04158265380739734 * RBC ** 2 - 0.9274332882414846 * RBC - 0.0004537166011694817 * Age ** 2 + 0.1205213006941625 * Age; const probability = 1 / (1 + Math.exp(-L)); const mlGlauIndex = 10 * probability;

Computational Nomogram

Step 3 visualizes the exact Gaussian Naive Bayes calculation rather than a conventional logistic-regression nomogram. For each predictor, the displayed contribution is Cj = ajXj² + bjXj. The five contributions are added to the model intercept to obtain L. The lower axes then map L to the posterior glaucoma probability and to the MLG-5 Index on its 0–10 scale. The visualization does not define a separate prediction model.

L = −12.527026 + CCTI + CUA/eGFR + CCr + CRBC + CAge Probability = 1 / [1 + exp(−L)] MLG-5 Index = 10 × Probability

Interpretation

The MLG-5 Index is a probability-scaled output of the fitted Gaussian Naive Bayes model rather than a separate regression score. A value of 5 corresponds to a model-estimated probability of 0.50, a value of 1 corresponds to 0.10, and a value of 8 corresponds to 0.80. Any operating threshold selected on the probability scale can be expressed on the index scale by multiplying the probability threshold by 10.
