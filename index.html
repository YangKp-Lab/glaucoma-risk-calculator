Research Methods

CHART-C Index Methodology

Model Framework

The CHART-C Index implements the final six-variable logistic regression model derived from a cross-national cohort analysis using NHANES and CHARLS data from two countries. CHART-C represents Conicity index, HbA1c, Age, Red blood cell count, Total cholesterol/HDL-C ratio, and Creatinine.

Variable Standardization

Each continuous predictor is standardized using the model-specific centering value and scale parameter shown in the final regression equation. The standardized value is then multiplied by its corresponding regression coefficient.

Logistic Regression Equation

logit(p) = −2.760629 + 0.127915 × ((CTI − 1.330112) / 0.086820) + 0.140389 × ((Cr − 0.948199) / 0.361071) − 0.131652 × ((RBC − 4.677461) / 0.497814) + 0.176341 × ((HbA1c − 5.849120) / 1.087302) − 0.184288 × ((TC_HDL − 4.064712) / 1.369750) + 0.619633 × ((Age − 59.834820) / 12.615600) p = 1 / (1 + exp(−logit(p)))

Web Calculation Logic

The browser computes the CHART-C linear predictor and predicted probability locally after the user clicks SUBMIT. No server-side computation is required for the risk estimate.

const eta = -2.760629 + 0.127915 * ((CTI - 1.330112) / 0.086820) + 0.140389 * ((Cr - 0.948199) / 0.361071) - 0.131652 * ((RBC - 4.677461) / 0.497814) + 0.176341 * ((HbA1c - 5.849120) / 1.087302) - 0.184288 * ((TC_HDL - 4.064712) / 1.369750) + 0.619633 * ((Age - 59.834820) / 12.615600); const probability = 1 / (1 + Math.exp(-eta));

CTI Definition

CTI represents the Conicity Index for central adiposity.

CTI = WC (m) / [0.109 × √(Weight / Height (m))]

Interpretation

The CHART-C Risk Score is the original model linear predictor (η) on the log-odds scale. Higher values indicate higher modeled glaucoma risk. Predicted Probability is obtained directly from the logistic transformation p = 1 / (1 + exp(−η)). The nomogram is a visual representation of the same fitted model rather than a separate prediction rule.
